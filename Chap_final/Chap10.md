# 유닉스 기초 10장 — 파일 아카이브와 백업 (한 장 요약)

> 흐름: **디스크 준비(01) → 사용량 확인(02) → 묶기(03) → 압축(04) → 복사·변환(05)**

---

## Section 01. 디스크 관리

새 디스크를 쓸 수 있게 만드는 3단계 과정.

| 단계 | 명령 | 의미 |
|------|------|------|
| ① 파티션 나누기 | `fdisk` | 디스크를 독립 영역으로 분할 (root 필요) |
| ② 파일시스템 생성 | `mkfs`, `mke2fs` | 파일·디렉터리 관리 구조 생성 (root 필요) |
| ③ 마운트 | `mount` | 디렉터리 트리에 연결해 접근 가능하게 |

- **장치명**: IDE/SCSI/SATA → `/dev/sd…`, NVMe → `/dev/nvme…`. 파티션은 뒤에 숫자(`/dev/sda1`).
- **마운트 확인**: `mount` 명령으로 마운트된 파일시스템 확인.
- **mkdir vs mount**: `mkdir`=같은 디스크 안에 폴더 생성 / `mount`=별개 디스크를 디렉터리에 연결.

## Section 02. 디스크 사용량 보기

| 명령 | 대상 | 주요 옵션 |
|------|------|-----------|
| `df` | **파일시스템별** 사용량 | `-h`(읽기쉬운단위) `-T`(종류표시) `-t ext4`(종류필터) `-a`(전체) `-m`(MB) |
| `du` | **디렉터리/사용자별** 사용량 | `-s`(합계만 요약) `-h`(읽기쉬운단위) |

- **`-T`(대문자) vs `-t`(소문자)**: `-T`=종류를 *표시*, `-t ext4`=그 종류만 *필터링*. 동작이 다른 별개 옵션.
- **`du -s`**: 하위 디렉터리 나열 없이 지정 디렉터리 **총합만** 출력.

**실습 10-1 예시**: `df -m` / `df -T` / `df -t ext4` / `du /boot` / `du -sh /usr`

## Section 03. 파일 아카이브 (묶기)

**아카이브 = 여러 파일을 하나로 묶기. 압축이 아님 (크기 거의 그대로).**

### tar 옵션
| 동작(택1) | 의미 | 보조(조합가능) | 의미 |
|------|------|------|------|
| `c` | 생성(create) | `f` | 파일명 지정 (**맨 뒤에**) |
| `x` | 풀기(extract) | `v` | 과정 출력 |
| `t` | 목록 보기 | `C` | 복원 디렉터리 지정 |
| `r` | 무조건 끝에 추가 | `z` | gzip 압축 |
| `u` | 변경·신규만 갱신 | `j` | bzip2 압축 |
|  |  | `h` | 심볼릭 링크 원본 포함 |

> `c`/`x`/`t`/`r`/`u`는 **동작 옵션 → 한 번에 하나만** (`ctx` 같이 쓰면 에러)
> `f`는 바로 뒤 단어를 파일명으로 읽음 → **항상 맨 뒤**

### tar 핵심 명령
```
tar cvf ch04.tar dir          # 생성
tar tvf ch04.tar              # 내용 확인 (풀기 전 경로 확인 권장)
tar xvf ch04.tar              # 풀기
tar xf ch04.tar -C /target    # 다른 디렉터리에 풀기
tar uvf ch04.tar dir          # 업데이트 (원래 경로 다시 지정)
tar rvf ch04.tar file         # 무조건 끝에 추가
```

- **u/r 주의**: 교체가 아니라 **끝에 덧붙임** → 같은 파일이 아카이브에 중복 저장. 풀면 나중 버전이 덮어써서 최신본만 남음.
- **압축 아카이브엔 u/r 불가** (`.tar.gz`, `.tbz2`는 중간 추가 안 됨).

### jar (Java Archive Tool)
```
jar cvf x.jar dir     # 묶기 + 압축 (jar는 압축이 기본!)
jar c0vf x.jar dir    # 0(영) = 압축 없이 묶기만
jar tvf / xvf         # 목록 / 풀기
```
- **tar vs jar**: tar는 "묶기"가 기본, jar는 "묶기+압축"이 기본 (정반대).
- jar 고유 옵션: `i`(색인) `m`(manifest) `0`(압축없음)

## Section 04. 파일 압축 (크기 줄이기)

| 명령 | 확장자 | 내용보기 | 해제 | 압축률 | 원본 |
|------|:---:|------|------|------|:---:|
| `compress` | `.Z` | `zcat` | `uncompress.real` | 낮음 | 삭제 |
| `gzip` | `.gz` | `zcat`/`gzcat` | `gunzip` (`-d`) | 중간 | 삭제 |
| `zip` | `.zip` | `unzip -l` | `unzip` | 중간 | **남음** |
| `bzip2` | `.bz2` | `bzcat` | `bunzip2` (`-d`) | **높음** | 삭제 |

**기억 패턴**
- 해제 = 앞에 **un**: gun‑zip, bun‑zip2, un‑zip, un‑compress
- 내용보기 = 확장자앞글자 + **cat**: gz→`zcat`, bz2→`bzcat`
- **원본 보존은 `zip`만** (나머지는 압축 시 원본 삭제)
- **압축률 최고 = bzip2** (단, 속도 느림)

**주요 옵션**: `-r`(디렉터리, gzip/zip) `-v`(정보) `-l`(내용) `-t`(검사) `-d`(해제) `--best`/`-9`(최대압축)
- compress·bzip2는 **디렉터리 직접 압축 불가**. zip·gzip은 `-r`로 가능.

### tar + 압축 (묶기와 압축 동시에)
| 명령 | 동작 | 확장자 |
|------|------|--------|
| `tar zcvf` / `zxvf` | gzip 압축 / 해제 | `.tar.gz`, `.tz` |
| `tar jcvf` / `jxvf` | bzip2 압축 / 해제 | `.tbz2` |

> `z`=gzip, `j`=bzip2 / 생성↔복원은 `c`↔`x`만 토글

## Section 05. 파일 복사와 변환 — dd (Data Dumper)

블록 단위로 데이터를 그대로 복사·변환. 디스크 이미지 백업, 파티션 백업에 사용.

```
dd [옵션] if=입력 of=출력
```

| 옵션 | 의미 |
|------|------|
| `if=FILE` | 입력 파일/장치 |
| `of=FILE` | 출력 파일/장치 |
| `bs=N` | 블록 크기 (기본 512byte) |
| `count=N` | N개 블록만 복사 |
| `skip=N` | **입력**에서 앞 N블록 건너뜀 |
| `seek=N` | **출력**에서 앞 N블록 건너뜀 |
| `conv=ucase` | 대문자 변환 |
| `conv=lcase` | 소문자 변환 |

**단위**: `c`=1B, `w`=2B, `b`=512B, `k`=1024B(`kB`=1000), `M`=1024², `G`=1024³

**사용 예**
```
dd if=a.txt of=b.txt                    # 복사
dd if=a.txt of=c.txt bs=100 count=1     # 앞 100byte만 복사
dd if=a.txt of=d.txt bs=1024 skip=1     # 앞 1024byte 빼고 복사
dd if=/dev/null of=a.txt count=1        # 내용 지우기
dd if=h.txt of=H.txt conv=ucase         # 대문자 변환
dd if=/dev/sda1 of=/dev/sdb1 bs=4096    # 디스크 통째 백업
```

- **skip vs seek**: sk**i**p=**i**nput, seek=output
- **주의**: `of=`에 디스크 장치 지정 시 통째로 덮어씀. 실습은 파일 대상으로만.

## 핵심 비교 요약

- **아카이브 ≠ 압축**: tar=묶기(크기 그대로), gzip/bzip2 등=크기 줄이기
- **압축률**: bzip2 > gzip ≈ zip > compress
- **원본 보존**: zip만 남김, 나머지는 삭제
- **tar 압축 옵션**: z=gzip, j=bzip2
- **tar f 옵션**: 항상 맨 뒤 (뒤 단어=파일명)
- **dd**: 블록 단위 그대로 복사 → 디스크 이미지 백업의 핵심
