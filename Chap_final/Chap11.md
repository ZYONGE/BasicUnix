# 11강 배시 셸 프로그래밍 — 한장 정리

---

## 1. 셸 스크립트

| 항목 | 내용 |
|------|------|
| 실행 방법 | `bash script.sh` / `sh script.sh` / `./script.sh` (권한 필요) |
| 실행 권한 부여 | `chmod +x script.sh` |
| 종료 | `exit [n]` — 종료 상태는 `$?`에 저장 |
| 종료값 | 0 = 성공(참), 0 이외 = 실패(거짓) |

### 구성 요소
| 요소 | 설명 |
|------|------|
| `#!` (셰뱅) | 첫 줄. 실행할 인터프리터 지정. 예) `#!/bin/bash` |
| `#` | 주석. 첫 줄 이후의 `#`은 모두 주석 |
| 셸 명령 | 셸이 실행 가능한 모든 명령 |
| 셸 프로그램 | 변수, 연산자, 제어문 등 |

### 셸 명령 실행 순서
```
앨리어스 → 키워드(if/while 등) → 함수 → 내장 명령(cd/echo 등) → PATH 경로 실행 파일
```

## 2. 셸 변수

### 종류 및 선언
```bash
변수명=값            # 셸 변수 (현재 셸에서만)
export 변수명=값     # 환경 변수 (자식 셸에 상속)
```
> ⚠️ `=` 앞뒤 공백 금지

### 변수 참조
| 형식 | 의미 |
|------|------|
| `$name` | name 값으로 대체 |
| `${name}` | name 값으로 대체 (인접 구문 있을 때 사용) |
| `${name:-word}` | 미정의/널이면 word 사용 (저장 ❌) |
| `${name:=word}` | 미정의/널이면 word 대입 후 사용 (저장 ✅) |
| `${name:+word}` | 정의돼 있고 널 아니면 word 사용 (반대 동작) |
| `${name:?word}` | 미정의/널이면 word 출력 후 종료 |

### 문자열 처리
| 형식 | 의미 |
|------|------|
| `${var%pattern}` | 뒤에서 최소 제거 |
| `${var%%pattern}` | 뒤에서 최대 제거 |
| `${var#pattern}` | 앞에서 최소 제거 |
| `${var##pattern}` | 앞에서 최대 제거 |
| `${#var}` | 문자 개수 |

### 명령행 인자
| 변수 | 의미 |
|------|------|
| `$0` | 스크립트 이름 |
| `$1`~`$9` | 1~9번째 인자 |
| `${10}` | 10번째 이상 인자 (중괄호 필수) |
| `$#` | 전체 인자 개수 ($0 제외) |
| `$*` | 모든 인자 |
| `$@` | 모든 인자 |
| `"$*"` | `"$1 $2 $3"` — 하나의 문자열 |
| `"$@"` | `"$1" "$2" "$3"` — 각각 분리 |
| `$?` | 최근 명령 종료값 |
| `set --` | 위치 인자 전부 삭제 |

### 인용 부호 & 명령 대체
| 기호 | 기능 |
|------|------|
| `' '` | 모든 특수문자 해석 차단 |
| `" "` | 변수·명령 대체만 허용 |
| `\` | 단일 문자 해석 차단 |
| `` ` ` `` / `$(명령)` | 명령 실행 결과를 문자열로 반환 |

## 3. 입출력

### 출력
```bash
echo "Hello"          # 자동 줄바꿈
echo -n "Hello"       # 줄바꿈 없음
printf "Hello\n"      # 줄바꿈 없음 (직접 \n 필요)
printf "%s, %d\n" "age" 20   # 형식 지정자 사용
```

### 입력 — `read`
| 형식 | 의미 |
|------|------|
| `read x` | 한 행 입력받아 x에 저장 |
| `read x y` | 첫 단어→x, 나머지→y |
| `read -p "msg" x` | 프롬프트 출력 후 x에 저장 |
| `read -a arr` | 배열로 저장 |
| `read -s -p "msg" x` | 입력 숨김 (비밀번호) |
| `read -n N x` | N글자만 입력 |
| `read -t N x` | N초 타임아웃 |
| `read -r line` | 역슬래시 그대로 읽기 |

## 4. 연산자

### 산술 연산 — `(( ))` / `let` / `expr`
```bash
(( result = x + y ))       # 권장. 공백 자유, $ 생략 가능
let "result = x + y"       # 공백 있으면 따옴표 필요
result=$(expr $x + $y)     # 공백 필수, * 는 \* 필요
echo $(( x * y ))          # 결과 바로 출력
```

| 연산자 | 의미 |
|--------|------|
| `+` `-` `*` `/` `%` | 사칙연산, 나머지 |
| `**` | 누승 (거듭제곱) |
| `+=` `-=` `*=` `/=` | 단축 대입 |
| `<<` `>>` | 비트 시프트 |
| `&` `\|` `^` `~` | 비트 AND/OR/XOR/NOT |

### 비교 연산자
| `(( ))` 안 | `[ ]` 안 | 의미 |
|-----------|---------|------|
| `==` | `-eq` | 같다 |
| `!=` | `-ne` | 다르다 |
| `>` | `-gt` | 크다 |
| `>=` | `-ge` | 크거나 같다 |
| `<` | `-lt` | 작다 |
| `<=` | `-le` | 작거나 같다 |

### 논리 연산자
| 연산자 | 의미 | 사용 위치 |
|--------|------|----------|
| `&&` | AND | `(( ))`, `[[ ]]` |
| `\|\|` | OR | `(( ))`, `[[ ]]` |
| `!` | NOT | `(( ))`, `[ ]`, `[[ ]]` |
| `-a` | AND | `[ ]` 안에서만 |
| `-o` | OR | `[ ]` 안에서만 |

### 문자열 연산자 — `[ ]` / `[[ ]]`
| 연산자 | 의미 |
|--------|------|
| `=` / `==` | 같다 |
| `!=` | 다르다 |
| `-z` | 빈 문자열 |
| `-n` | 빈 문자열이 아님 |
| `=~` | 정규표현식 매칭 (`[[ ]]`만) |

### 파일 테스트 — `[ ]` / `[[ ]]`
| 플래그 | 의미 | 플래그 | 의미 |
|--------|------|--------|------|
| `-e` / `-a` | 존재 | `-r` | 읽기 가능 |
| `-f` | 일반 파일 | `-w` | 쓰기 가능 |
| `-d` | 디렉터리 | `-x` | 실행 가능 |
| `-L` | 심볼릭 링크 | `-s` | 크기 > 0 |
| `-O` | 소유자 일치 | `-u` | setuid |
| `-G` | 그룹 ID 일치 | `-g` | setgid |
| `-S` | 소켓 파일 | `-k` | sticky bit |

### `(( ))` vs `[[ ]]`
| | `(( ))` | `[[ ]]` |
|--|---------|---------|
| 용도 | 숫자 연산·비교 | 문자열·파일 비교 |
| 연산자 | `>=` `<=` `==` | `=` `!=` `-z` `-n` |
| `$` | 생략 가능 | 필요 |
| 패턴 매칭 | ❌ | ✅ (`*` `?` `[ ]` `=~`) |

## 5. 제어문

### if 문
```bash
if 조건; then
    명령
elif 조건; then
    명령
else
    명령
fi
```

### case 문
```bash
case 변수 in
    value1)   명령 ;;
    v1|v2)    명령 ;;     # | 로 OR
    [0-9])    명령 ;;     # 패턴
    [aA-C]*)  명령 ;;     # 와일드카드
    *)        명령 ;;     # 기본값
esac
```

### for 문
```bash
for 변수 in list; do 명령; done
for i in {1..10}; do 명령; done        # 범위
for i in {0..10..2}; do 명령; done     # 스텝 (Bash 4.0+)
for i in $(seq 1 "$1"); do 명령; done  # 변수 범위
for (( i=0; i<10; i++ )); do 명령; done  # C-style
for arg in "$@"; do 명령; done         # 명령행 인자
```

### while 문
```bash
while 조건; do
    명령
done

while :; do 명령; done      # 무한 루프 방법 1
while true; do 명령; done   # 무한 루프 방법 2
```

### until 문
```bash
until 조건; do    # 조건이 참이 될 때까지 반복
    명령
done
```

### select 문
```bash
PS3="프롬프트 : "
select 변수 in list; do
    case $변수 in
        항목) 명령 ;;
        quit) break ;;
    esac
done
```

### 루프 제어
| 명령 | 의미 |
|------|------|
| `break` | 반복문 탈출 |
| `break N` | N번째 바깥 루프 탈출 |
| `continue` | 루프 처음으로 돌아감 |
| `continue N` | N번째 바깥 루프 처음으로 |

## 6. 배열

```bash
arr=("v1" "v2" "v3")   # 선언
${arr[0]}               # 인덱스 참조 (0부터 시작)
${arr[@]} / ${arr[*]}   # 모든 원소
${!arr[@]}              # 인덱스 번호 목록
${#arr[@]}              # 배열 크기 (원소 개수)
${#arr[0]}              # 0번 원소의 문자 길이
```

## 7. 함수

## 자주 쓰는 패턴 모음

```bash
# 산술 결과 출력
echo "합 = $((x + y))"

# 배열 입력받기
read -a arr
for i in "${arr[@]}"; do echo $i; done

# 파일 한 줄씩 읽기
while read -r line; do echo $line; done < file.txt

# 숫자인지 확인
if [[ $x =~ ^[0-9]+$ ]]; then echo "숫자"; fi

# 디렉터리 없으면 생성
if [[ ! -d $DIR ]]; then mkdir -p $DIR; fi

# 명령행 인자 없으면 종료
if (( $# == 0 )); then echo "인자 필요"; exit 1; fi
```

---

> **핵심 3가지**
> 1. 산술 연산은 반드시 `$(( ))` 또는 `(( ))` 안에서
> 2. `=` 앞뒤 공백 금지, 배열 인덱스는 0부터
> 3. `if`는 종료값 0이 참, `(( ))`는 숫자, `[[ ]]`는 문자열·파일
