## 🔹 PART 1. 라이브러리

### 개념
미리 컴파일된 함수·변수 묶음. 두 종류가 있다.

| 구분 | 정적 `.a` (Archive) | 공유·동적 `.so` (Shared Object) |
|---|---|---|
| 코드 위치 | 실행파일 안에 **복사됨** | 실행 시 **밖에서 불러옴** |
| 링크 시점 | 컴파일 시 (정적 링크) | 실행 시 (동적 링크) |
| 실행파일 크기 | 큼 | 작음 |
| 실행 속도 | 빠름 | 약간 느림 |
| 라이브러리 수정 시 | **재컴파일 필요** | `.so`만 교체하면 됨 |
| 둘 다 있으면 | `-static`으로 강제 | **기본 선택됨** |

> OS별 확장자: 리눅스 `.so` · HP-UX `.sl` · 윈도우 `.dll`

### 만드는 명령
```bash
# 정적 라이브러리 (.a)
gcc -c file1.c file2.c                 # ① .o(목적파일) 생성
ar rscv libmyfunc.a file1.o file2.o    # ② .o들을 .a로 묶기

# 공유 라이브러리 (.so)
gcc -shared -fPIC -o libmyfunc.so file1.c file2.c

# 사용 (정적·공유 공통)
gcc -o prog main.c -L./ -lmyfunc       # -L:폴더  -l:이름(lib·확장자 제거)
```

### 주요 옵션
| 옵션 | 의미 |
|---|---|
| `ar rscv` | r=추가, s=색인, c=생성, v=출력 |
| `ranlib` | 정적 라이브러리 색인만 따로 생성 |
| `-fPIC` | 위치 독립 코드 (공유 라이브러리 필수) |
| `-shared` | 공유 라이브러리 생성 |
| `-static` | 정적 링크 강제 |
| `-L경로` | 라이브러리 **찾을 폴더** (대문자) |
| `-l이름` | 쓸 라이브러리 **이름** (소문자) |
| `-I경로` | 헤더(.h) 찾을 폴더 |

### `.so` 위치 알려주기 (실행 시 못 찾을 때)
```bash
# 방법1: 환경변수 (~/.bash_profile)
export LD_LIBRARY_PATH=$LD_LIBRARY_PATH:내경로
# 방법2: 시스템 등록 (/etc/ld.so.conf 수정 후)
ldconfig
```

### 진단 도구
| 명령 | 기능 |
|---|---|
| `nm 파일` | 라이브러리 내부 함수·변수 목록 |
| `ldd 실행파일` | 필요한 공유 라이브러리 목록 |
| `readelf -a` | ELF 바이너리 상세·의존 정보 |

## 🔹 PART 2. Make / Makefile

### 개념
컴파일 자동화 도구. **바뀐 파일만** 골라 재컴파일한다.
판단 기준 = 파일 **수정 시각(mtime)** 비교.

### 기본 문법 ⭐
```makefile
타겟 : 종속항1 종속항2      # 규칙문 (콜론)
→탭→ 명령어                # 명령문 (반드시 탭으로 시작!)
```
- 타겟 = 만들 결과물 / 종속항 = 재료 / 명령 = 실제 실행
- 명령 앞은 **무조건 탭** (스페이스 X) ← 최다 함정
- `#` 주석 · `\` 줄 이어쓰기 · 공란 무시
- 맨 위 타겟부터 실행 (보통 `all` 더미 타겟)

### 매크로 (변수)
```makefile
CC = gcc
$(CC) -c main.c        # 사용 시 gcc로 치환. 이름은 대문자 관례
```

### 대입 연산자
| 연산자 | 의미 |
|---|---|
| `=` | 재귀적 (나중 정의도 반영) |
| `:=` | 단순 (그 줄까지만 반영) |
| `+=` | 기존 값에 이어붙임 |
| `?=` | 앞에 없을 때만 정의 |

### 자동 매크로 ⭐⭐
| 기호 | 의미 |
|---|---|
| `$@` | 타겟 이름 |
| `$?` | 타겟보다 **최근 수정된** 종속항 |
| `$^` | 종속항 전체 |
| `$<` | 첫 번째 종속항 (확장자 규칙용) |
| `$*` | 확장자 뺀 이름 |

### 확장자 규칙 (반복 제거)
```makefile
%.o : %.c              # 모든 .c를 .o로 (= 옛표기 .c.o:)
	$(CC) -c -o $@ $<  # 확장자 규칙에선 $< 사용
```

### 자동화 패턴 (파일명 안 적기)
```makefile
SRCS = $(wildcard *.c)   # 현재 폴더 .c 자동 수집
OBJS = $(SRCS:.c=.o)     # 이름의 .c→.o 치환 (목록만, 실제 컴파일 X)
```

### gcc 주요 옵션
| 옵션 | 의미 |
|---|---|
| `-c` | 컴파일만(.o), 링크 X |
| `-o 이름` | 출력 파일명 |
| `-Wall` | 모든 경고 |
| `-O2 / -O3` | 최적화 |
| `-g` | 디버깅 정보 |
| `-D` | 매크로 정의 |

## 🔹 PART 3. 특수 타겟 & 명령 규칙

| 문법 | 의미 |
|---|---|
| `clean :` | 더미 타겟 (파일 안 만들고 명령만) |
| `;` | 앞 실패해도 뒤 실행 |
| `&&` | 앞 **성공해야** 뒤 실행 (안전, cd에 사용) |
| `@명령` | 명령 화면에 안 보임 |
| `-명령` | 에러 무시하고 계속 |
| `.SILENT :` | 전체 명령 숨김 (@의 전체판) |
| `.IGNORE :` | 전체 에러 무시 (-의 전체판) |
| `$$(변수)` | 셸 변수 참조 ($ 두 개) |

> ⚠️ 명령줄마다 별개 셸 → `cd`는 다음 줄에 안 이어짐. `cd dir && 명령`으로 붙여 쓸 것.

## 🔹 PART 4. 프로젝트 관리 (분산 폴더)

| 방법 | 핵심 |
|---|---|
| 경로 지정 | `cd 폴더 && $(MAKE)` = `make -C 폴더` |
| **VPATH** | `VPATH = a b c` → 다른 폴더 소스도 검색 (단, 이름 중복 금지) |
| 재귀 make | `for`문 + `export`로 매크로 하위 전달 |

### 조건문
```makefile
ifeq ($(CC), gcc)   # ifeq/ifneq/ifdef/ifndef
	@echo "gcc"
else
	@echo "$(CC)"
endif               # 항상 endif로 닫기
```

### 함수
| 함수 | 기능 |
|---|---|
| `$(shell ls *.c)` | 셸 명령 결과 가져오기 |
| `$(subst a,b,문자열)` | 글자 그대로 치환 |
| `$(patsubst %.c,%.o,문자열)` | 패턴(`%`) 치환 |
| `$(wildcard *.c)` | 파일 목록 수집 |

## ✅ 시험 포인트 압축
- 정적 `.a`=ar / 공유 `.so`=`gcc -shared -fPIC`
- 둘 다 있으면 **`.so` 기본**, 정적은 **`-static`**
- 크기: 정적 > 공유
- 명령 앞은 **탭**, `cd`는 **`&&`**
- 자동매크로 `$@`타겟 `$?`최신종속 `$^`전체 `$<`첫번째
- `-shared`는 **라이브러리 만들 때만** (실행파일 공유 링크엔 옵션 없음)
