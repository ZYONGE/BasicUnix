## ① 사용자 정보 관련 파일 (5개)

| 파일 | 역할 | 권한 | 항목 수 |
|------|------|------|:---:|
| `/etc/passwd` | 기본 계정 정보 | 누구나 읽기 | **7개** |
| `/etc/shadow` | 암호 정보 | root만 읽기/쓰기 | **9개** |
| `/etc/login.defs` | 계정 설정 기본값 | — | — |
| `/etc/group` | 그룹 정보 | — | **4개** |
| `/etc/gshadow` | 그룹 암호 | — | **4개** |

모든 항목은 콜론(`:`)으로 구분. 백업 파일은 이름 끝에 `-` (예: `/etc/passwd-`)

### `/etc/passwd` 구조 (7항목)
```
로그인ID : 암호(x) : UID : GID : 설명 : 홈디렉터리 : 로그인셸
```
- 암호는 `x` (실제 암호는 shadow에)
- **UID 0~999, 65534 = 시스템 예약**, 일반 사용자는 **1000번부터**
- 시스템 계정 셸은 보통 `/usr/sbin/nologin` (로그인 불가)

### `/etc/shadow` 구조 (9항목)
```
로그인ID : 암호 : 최종변경일 : MIN : MAX : WARNING : INACTIVE : EXPIRE : Flag
```
- 암호는 암호화 저장, 시스템 계정은 `*` 또는 `!`
- 날짜는 **1970-01-01 기준 경과 일수**
- MIN: 변경 후 최소기간 / MAX: 최대 사용기간 / WARNING: 만료 전 경고일 / INACTIVE: 만료 후 잠금까지 / EXPIRE: 계정 만료일

### `/etc/group` 구조 (4항목)
```
그룹이름 : x : GID : 그룹멤버(쉼표 구분)
```

### `/etc/gshadow` 구조 (4항목)
```
그룹이름 : 그룹암호 : 관리자 : 그룹멤버
```

## ② 사용자 정보 보기 명령

### 로그인한 사용자 보기
| 명령 | 설명 |
|------|------|
| `users` | 로그인 중인 사용자명만 출력 |
| `who` | 사용자명·터미널·로그인 시간·접속 IP |
| `w` | who 정보 + 작업/CPU/시스템 로드 |

**who 주요 옵션**
| 옵션 | 기능 |
|:---:|------|
| `-H` | 항목 제목 함께 출력 |
| `-m` | 현재 사용자 계정만 |
| `-u` | 로그인 중 계정 + 대기시간 (`.`=1분 이내, `old`=24h 이상) |
| `-q` | 로그인 사용자 수 + 이름 |
| `-b` | 시스템 부팅 날짜·시간 |
| `-r` | 현재 런레벨 (5 = GUI) |
| `-a` | 주요 옵션 한꺼번에 |

**w 옵션**: `-s` = 간략 출력 (로그인시간·JCPU·PCPU 생략)

### 자신의 정보 보기
| 명령 | 출력 | 보는 ID |
|------|------|:---:|
| `who am i` | 로그인 정보 중 자신 | **UID** |
| `whoami` | 자신의 로그인 ID | **EUID** |
| `id` | UID·GID·그룹 전체 | **EUID** |

### 기타
- `last` — 사용자 로그인 기록
- `groups [계정]` — 소속 그룹 확인 (미지정 시 본인)

## ③ root 권한 사용 방법

### su — 사용자 전환
| 명령 | 동작 | 작업 디렉터리 |
|------|------|------|
| `su` | ID만 전환, **환경 미적용** | 그대로 유지 |
| `su -` | **새 로그인처럼 환경 전체 적용** | 대상 계정 홈으로 이동 |
| `su -s /bin/sh` | 셸 지정하여 전환 | — |

- 계정 미지정 시 → **root로 전환** (root 암호 필요)
- 전환에서 빠져나오기: `exit` 또는 `Ctrl+D`

### sudo — 일시적 root 권한 실행
- 일반 사용자가 root 권한으로 명령 실행 (`sudo 명령`)
- **본인 암호** 입력 (root 암호 X)
- 권한 설정: `/etc/sudoers` (root만 수정, **`visudo`로 편집** 권장 — 문법 검사)
- sudoers 미등록 사용자가 sudo 시도 → `사용자 is not in the sudoers file.`
- 예: `sudo useradd user3`, `sudo passwd user2`

## ④ UID와 EUID ⭐핵심

| 구분 | UID (Real UID) | EUID (Effective UID) |
|------|------|------|
| 의미 | 실제 로그인 계정 (소유자) | 권한 판단에 쓰이는 ID |
| 정해지는 시점 | 로그인 시 | 실행/전환 시 |
| 변경 여부 | 거의 안 바뀜 | setuid·su로 바뀜 |
| 확인 명령 | `who am i`, `who -m` | `whoami`, `id` |

**평소에는 UID == EUID** → 차이는 두 경우에 드러남:

1. **`su` 전환**: UID는 원래 계정 유지, EUID만 전환 계정으로 변경
   - 예) user1 로그인 후 `su user2` →  `who am i`=user1, `whoami`=user2

2. **setuid 실행 파일**: 실행 시 EUID가 **파일 소유자**의 UID로 변경
   - 대표 예) `passwd` — root 소유 + setuid → 일반 사용자도 root만 쓰는 `/etc/shadow` 수정 가능
   - 확인: `ls -l /usr/bin/passwd` → `-rwsr-xr-x` (소유자 x 자리에 **`s`**)

> 💡 **비유**: UID = 신분증의 본명 / EUID = 지금 들고 있는 출입증
> 시스템이 권한을 판단할 때 보는 것은 **EUID(출입증)**
